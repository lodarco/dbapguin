DBApguin

A desktop PostgreSQL DBA console. One window for watching a live server, working out why it is slow, and moving schemas and data around.

I built it for my own daily work as a DBA, and I share it in case it helps you too.

Free for everyone - no licence key, no trial, no account
Download User guide On GitHub

What is inside

Watching a live server

Sessions and the load they make, blocking pairs, long transactions, idle-in-transaction, connection limits, temp-file spills, checkpoints, replication lag and slots.

Why it is slow

Index, cache, autovacuum and setup advisors. Bloat estimates, duplicate and unused indexes, query history, workload reports and AWR-style snapshots you can compare.

Moving things

Clone a table or a whole schema, merge schemas, copy a table across databases or servers, compare two schemas and get a reviewable script, back up and restore.

Everyday work

SQL editor with EXPLAIN, object tree, privileges and roles, column and sequence editors, maintenance with the options the connected server actually supports.

Extending it

Plugins add checks, menu entries and tabs without a new version, and the app includes a builder for writing your own. Nothing checks who made a plugin, so install only ones from publishers you trust.

Every destructive action shows you the statement before it runs.

Linux DBApguin-x86_64.AppImage - chmod +x and run.
Or dbapguin_<version>_amd64.deb for a menu entry.
Windows DBApguin-<version>-setup.exe, or the portable zip if you would rather not install.
macOS DBApguin-<version>-macOS-x86_64.dmg, drag to Applications. Intel build.

Each release carries a SHA256SUMS. Check it before installing:

sha256sum -c SHA256SUMS

Neither the Windows nor the macOS build is code-signed. SmartScreen warns on first run ("More info", then "Run anyway"); macOS needs right-click then Open the first time. Signing costs money the project does not have.

PostgreSQL versions

Tested against PostgreSQL 13 and newer.

It connects to older servers too, and the rule is do what the version allows, do not refuse: a check that can leave out a column the server lacks does that and says so in a short note, rather than failing. Every release round is exercised against real 9.4, 9.6, 10, 11, 12, 13, 14 and 18 servers. Below 9.4 the catalogues have diverged too far and the app does not claim to work.

PostgreSQL 19 is measured too - on 19rc1, the release candidate, since 19.0 is not out yet: every check runs on it, and Tuning & diagnostics → Ready for PostgreSQL 19? goes through 19's list of incompatibilities against your server before you upgrade.

Getting in touch

Bugs and questions: open an issue, or write to dbapguin@gmail.com.

The app can assemble the report for you. Settings → Report a bug fills in the version, the commit and the last lines of the error log, redacts passwords, hostnames and IP addresses, shows you the exact text, and leaves sending it to you - nothing goes anywhere on its own.

Terms and privacy

DBApguin is free for private and commercial use alike - no licence key, no activation, no trial that runs out, and no feature held back. Use it freely, do not sell it, and do not present it as your own work.

Nothing is sent anywhere. No telemetry, no update check, no account, no network traffic beyond the database connections you configure yourself. The one exception is a plugin you choose to install: its traffic is its own.

The SQL it runs

The application's source is not published. The SQL it sends to your servers is: every statement DBApguin can run, with where it lives in the app, read out of the source by a script rather than written by hand, under the PostgreSQL Licence - the SQL catalogue. None of it is secret anyway: it is in your server's pg_stat_statements and log the moment it runs, and the user guide explains what each check is for.

How DBApguin is made

I built DBApguin for my own daily work as a DBA - one window for the everyday questions instead of ten tools - and I share it because it may help others too: experienced DBAs, and just as much people who know less about databases. It is free of charge.

It is written with the help of AI coding assistants. Every change is designed, reviewed and tested by me - automated tests against PostgreSQL 9.4 to 19 (19rc1), and by hand in the app itself. Testing goes on with every release, on a best-effort basis: DBApguin is provided as is, without warranty. Bug reports are welcome.
